# Genus-2 Bolza Mean-Value Morph Generation

This note records the corrected genus-2 workflow. It does not use the older
`example_genus2_boundary_vertices_embedded_irregular_1_20.json` triangulation.
The initial topology is generated from a regular 8-gon fundamental domain with
random interior points and a local Bowyer-Watson Delaunay triangulation.

## Fundamental Domain

- Surface: genus-2 Bolza surface.
- Fundamental polygon: regular 8-gon in the Poincare disk.
- Boundary radius: `0.8408964152537146`.
- Side subdivisions: `4`, so each side has three non-corner boundary vertices.
- Side pairings:
  - side `0` to side `2`
  - side `1` to side `3`
  - side `4` to side `6`
  - side `5` to side `7`

The side-pairing constraints are disk Mobius transformations. During
mean-value weight computation, the corner stars are automatically completed by
the same Mobius side attachments; the solver constraints are not changed.

## Convexity Check

Convexity is checked hyperbolically, not by Euclidean chord angles. For each
quad or pentagon face and each vertex of that face:

1. Compute the tangent direction of the incoming Poincare geodesic.
2. Compute the tangent direction of the outgoing Poincare geodesic.
3. Measure the signed turn from incoming to outgoing.
4. Accept the vertex only if the turn has the face orientation sign, which is
   equivalent to interior angle less than `pi` for these embedded cells.

This check is implemented in `generate_genus2_quad_pent_graph.py` as
`nonconvex_hyperbolic_faces`.

## Minimized Triangulation Endpoints

All-one endpoint:

```bash
python3 poincare_harmonic_map.py \
  input/example_genus2_bolza_delaunay_irregular.json \
  --output input/example_genus2_bolza_delaunay_all_1_solution.json \
  --iterations 8000 \
  --step-size 0.006 \
  --tolerance 1e-9
```

Half-10 endpoint input:

```bash
python3 -c 'import json; p="input/example_genus2_bolza_delaunay_irregular.json"; q="input/example_genus2_bolza_delaunay_half_10.json"; data=json.load(open(p)); n=len(data["edges"]); data["edge_weights"]=[10.0 if i<n//2 else 1.0 for i in range(n)]; data["directed_edge_weights"]=[[w,w] for w in data["edge_weights"]]; data["directed_edge_weight_operator"]="energy"; data["name"]="genus2_bolza_delaunay_half_10"; data["description"]="Genus-2 Bolza Delaunay topology with half edge weights 10 and half edge weights 1."; data.setdefault("metadata",{})["endpoint_weight_pattern"]="first half 10, second half 1"; json.dump(data, open(q,"w"), indent=2); open(q,"a").write("\n")'
```

Half-10 endpoint:

## Quad/Pent Cell Graph

The cell graph is generated by removing selected Delaunay construction edges
from the minimized all-one triangulation. Candidate merges are accepted only if
the resulting quad/pent cells are hyperbolically convex and the finite quotient
graph remains 3-connected.

Command:

```bash
python3 generate_genus2_quad_pent_graph.py \
  --quads 25 \
  --pentagons 6 \
  --seed-limit 700
```

Outputs:

- `input/example_genus2_bolza_convex_quad_pent_graph.json`
- `output/genus2_bolza_convex_quad_pent_graph.svg`

Face histogram:

- triangles: `270`
- quads: `25`
- pentagons: `6`

Quotient check:

- quotient vertices: `167`
- quotient edges: `470`
- minimum quotient degree: `3`
- finite quotient 3-connected check: passed

## Mean-Value Morphs

The morphs use mean-value directed edge weights at the minimized all-one
endpoint and mean-value directed edge weights at the minimized half-10 endpoint.
Energy is allowed to increase during morphing, so solver convergence is judged
by relative step change, with line-search minimization disabled.

Triangulation morph:

```bash
python3 make_boundary_weight_morph_mean_value.py \
  --base input/example_genus2_bolza_delaunay_all_1_solution.json \
  --target-embedding input/example_genus2_bolza_delaunay_half_10_solution.json \
  --output-dir boundary_morph_genus2_bolza_triangulation_mean_value_all1_to_half10_frames \
  --frames 25 \
  --start-directed-weights mean_value \
  --target-directed-weights mean_value_from_target \
  --normalization unnormalized \
  --directed-edge-weight-operator mean_value \
  --iterations 3000 \
  --step-size 0.001 \
  --tolerance 1e-8 \
  --line-search-objective none \
  --convergence-criterion relative_step \
  --skip-face-orientation-check
```

```bash
python3 make_boundary_weight_morph_mean_value.py \
```
